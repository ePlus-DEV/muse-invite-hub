How do invite codes work?
  1. Copy a code from the directory above.
  2. Open Muse and find the invite-code redemption option in Settings.
  3. Enter the code in Muse and review the eligibility and reward terms there.

Only Muse can confirm whether a code can be redeemed. Copying a code here does not redeem it or consume an invite.
