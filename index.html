How do invite codes work?
  1. Copy a code from the directory above.
  2. Open Muse and find the invite-code redemption option in Settings.
  3. Enter the code in Muse and review the eligibility and reward terms there.

Only Muse can confirm whether a code can be redeemed. Copying a code here does not redeem it or consume an invite.

What is Muse Invite Hub?

Muse Invite Hub is a free, open-source community directory to find, copy and share Muse invite codes. It is maintained independently by ePlus.DEV and is not an official Muse or Meta service.

Does a listed invite code guarantee Muse access?

No. Codes, feedback and remaining counts are community reports that may be outdated. Only Muse can confirm whether a code can be redeemed and what terms or rewards apply.

How can I share or report a code?

Use a public GitHub Issue to share a code or report your experience. Maintainers review submissions before publication. Never share passwords or private tokens.
