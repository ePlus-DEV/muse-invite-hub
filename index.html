GOOD TO KNOW

A few things to know.

Does a listed code guarantee Muse access?+

No. Only Muse can confirm redemption, eligibility, regional availability, or any token rewards. Codes may stop working without notice.

Where do I enter an invite code?+

On Muse web, users report Settings → General → Usage → Redeem invite code; on mobile, Settings → Redeem token. Community guides describe a 48-hour redemption window after signup, but only the terms in your Muse account are authoritative.

How can I add or report a code?+

Use the Share a code or Report a code GitHub Issue Form. Maintainers review community submissions before publishing changes.

What do I get for redeeming a code?+

Muse has previously described a referral offer of 1 billion tokens to each eligible participant when a new member redeems a code within 48 hours. This is not a guaranteed current reward. Check the terms shown inside your Muse account; eligibility, amount and limits can change.

Is this an official Muse website?+

No. Muse Invite Hub is an independent open-source community project maintained by ePlus.DEV. It is not affiliated with, sponsored by, or endorsed by Muse or Meta.
