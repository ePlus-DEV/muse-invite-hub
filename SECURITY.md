# Security and privacy

Muse Invite Hub is a public static directory. It does not sign into Muse, redeem invitations for users or store account credentials.

- Submit only publicly shareable invite/referral codes.
- GitHub Issues are public. Never share passwords, account recovery codes, authentication codes, sessions, cookies, email addresses, phone numbers or private screenshots.
- Maintainers review submissions. Untrusted GitHub Issue text must not be executed or injected as HTML.
- Codes may fail without notice; no listed code guarantees Muse access or rewards.
- Use the [Report a code issue form](https://github.com/ePlus-DEV/muse-invite-hub/issues/new?template=report-code.yml) for broken listings.
- For a security vulnerability, avoid disclosing secrets publicly; use GitHub private security reporting (if enabled) or contact maintainers privately.

Offensive, spammy and sensitive submissions may be removed.
